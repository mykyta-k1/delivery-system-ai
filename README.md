# Delivery Grid Core

## 🎯 Опис Проєкту

**Delivery Grid Core** — це ядро системи розподілу замовлень для служби доставки, що працює у віртуальній координатній сітці. Система автоматично призначає кур'єрів, враховуючи їх місцезнаходження, тип транспорту та історію виконаних замовлень (справедливий розподіл).

### Ключові Можливості
- 📍 **Координатна система** (без прив'язки до реальних карт).
- ⚖️ **Справедливий розподіл** (Fairness Logic): пріоритет кур'єрам з меншою кількістю замовлень при малій різниці відстаней (< 1 км).
- ⏳ **Черга замовлень**: якщо немає вільних кур'єрів, замовлення очікують у статусі `NEW`.
- 🔄 **Автоматичне призначення**: при звільненні кур'єра система автоматично бере найстаріше замовлення з черги.
- 📦 **Життєвий цикл замовлення** (NEW → ASSIGNED → COMPLETED).
- 🚚 **Різні типи транспорту**: Пішохід (5кг), Велосипед (15кг), Авто (50кг).

## 🏗 Життєвий Цикл Замовлення

```mermaid
graph TD
    A[Клієнт створює Замовлення] --> B{Є вільний та здатний кур'єр?}
    B -- Так --> C[Призначити найближчого/справедливого]
    C --> D[Кур'єр BUSY / Замовлення ASSIGNED]
    B -- Ні --> E[Замовлення в черзі (NEW)]
    D --> F[Кур'єр завершує (COMPLETE)]
    F --> G[Кур'єр FREE / Рейтинг +1]
    G --> H{Є замовлення в черзі?}
    H -- Так --> C
    H -- Ні --> I[Кур'єр чекає]
```

## 🚀 Як Запустити

### Вимоги
- Java 17+
- Maven 3.6+

### Запуск Застосунку

```bash
# Використовуючи Maven Wrapper (рекомендовано)
./mvnw spring-boot:run
```
Застосунок буде доступний за адресою `http://localhost:8080`.

### Запуск Тестів

```bash
./mvnw clean test
```

## 📚 API Документація

Інтерактивна документація Swagger UI доступна після запуску:
👉 [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)

### Основні Ендпоінти

#### Створити Замовлення
`POST /api/v1/orders`
```json
{
  "source": {"x": 10, "y": 10},
  "destination": {"x": 50, "y": 50},
  "weight": 5.0
}
```

#### Завершити Замовлення
`POST /api/v1/orders/{id}/complete`
Це звільняє кур'єра та автоматично перевіряє чергу для призначення нового замовлення.
